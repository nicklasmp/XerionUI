XerionUI sidebar — tre nye bud

Inspireret af EllesmereUI-listen: ingen ikoner, ren tekst, tydelige gruppeoverskrifter. Alle tre er klikbare. Skriv A, B eller C (eller bland), så bygger jeg den i spillet.

Fælles for alle: modulnavne i den tunge smalle font, slukkede moduler dæmpet, amber/rød prik ved problem, filter All/Active/Inactive og søgning beholdes, grupper kan foldes. Spell-ikonerne udgår, fordi de gør listen uroligere end navnene.
